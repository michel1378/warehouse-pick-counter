# Фиксированный подбор и слепая проверка — 28.10.2026

## Зафиксированный метод

По запросу владельца автоматический выбор методов удалён. Для всех вещей и посадок используется один вариант: **линейный прогноз с локальной поправкой к примерам владельца**. Новые параметры не подбирались.

- Рост и вес обучаются совместно, отдельно для каждой вещи и посадки; знаки коэффициентов не ограничены.
- Масштабы расстояния: **7 см / 10 кг**.
- Штраф линейных наклонов: **0.25**, свободный член не штрафуется.
- Поправка — среднее остаточных ошибок с весами **1/d²** по всем примерам выбранной посадки.
- Нет жёсткого top-k и требования двух соседних строк. Даже один пример позволяет получить предварительный ответ рядом с ним.
- Индексы берутся из сохранённого размерного ряда вещи. Универсальных смещений для посадок нет.
- Уникальные точные рекомендации возвращаются без изменения; локальная поправка непрерывно привязывает соседний прогноз к ним.

Первоначальный дефект устранён: «Лонгслив Мужик», regular, **175/67 → M**, **175/68 → M**. Причиной старого скачка была отдельная ветка точного ответа рядом с регрессионной поверхностью, не проходившей через рекомендации владельца.

Обязательной монотонности по росту нет. «Футболка Черный Холод (+Серый)»: **190/85 → XL** и **167/85 → 2XL** сохранены и не объявляются ошибкой. Реальный конфликт определяется только разными размерами для полностью одинаковых роста, веса и посадки; автоматически такие строки не исправляются. В текущем экспорте таких конфликтов нет.

## Слепая проверка: сначала ответы владельца

Подготовлены **12 новых сочетаний**, по три для «Лонгслив Мужик», «Асим Рубашка», «Лонгслив Альпака (в полоску)» и «Рубашка Лучшая (дистресс)». Все regular, без совпадений с существующими строками, внутри заполненных диапазонов. Выбраны нижняя, средняя и верхняя области параметров, без просмотра прогнозов модели. Это покрытие областей, а не обещание заранее заданных размеров ответа.

Вопросы без ответов: [size-blind-check-20261028.json](../tests/fixtures/size-blind-check-20261028.json). **Прогнозы для этих 12 сочетаний до ответа владельца не вычислялись и не сохранялись.** В базу вопросы не добавлялись.

Для воспроизводимости локально сохранены контрольные суммы SHA-256 двух файлов алгоритма, исходной тестовой копии каталога и списка вопросов (`tests/fixtures/size-blind-lock-20261028.json`). Параметры 7/10, 0.25, степень 2 также записаны в этом файле. Локальный тест проверяет совпадение контрольных сумм. Файл контрольных сумм и сырой каталог не включаются в коммит.

При сравнении после получения всех 12 размеров владельца соблюдён протокол:

1. Контрольные суммы проверены; использован тот же исходный каталог, ответы в обучение не добавлены.
2. Прогнозы фиксированного метода сопоставлены с ответами владельца без подстройки.
3. Итог: **9/12 совпадений, 3 ошибки на один размер в большую сторону, 0 ошибок на два и более, 0 отказов**.
4. Промахи: «Мужик» 181/77 — M против L; 192/92 — XL против 2XL; «Асим Рубашка» 191/81 — 2XL против 3XL. Порядок: владелец против прогноза. Только второй промах имел предупреждение о границе; отсутствие предупреждения не является гарантией правильности.
5. Метод, параметры и исходные данные после ответов не менялись. Будущие изменения потребуют новой проверки.

12 экспертных ответов — небольшая дополнительная проверка, а не статистическое доказательство точности посадки. Сочетания выбраны по известным параметрам каталога; это не случайная выборка новых реальных покупателей.

Тесты проверяют сохранение рекомендаций, отсутствие ложного конфликта футболки, окрестности, исключение дублей, метрики фиксированного метода, отсутствие автоматического выбора, валидность слепых вопросов и контрольные суммы.
