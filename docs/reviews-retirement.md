# Удаление раздела «Отзывы»

Удалены страницы сотрудников и администратора, API генерации, навигация,
разрешение в форме сотрудника, код генерации, стили и зависимость OpenAI.
Старое разрешение `reviews` в сессии игнорируется. Сотрудник без права
комплектации попадает в каталог размеров, а не на удалённую страницу.

После успешной публикации этой версии выполнить `scripts/retire-reviews.sql`:
он удаляет только историю генерации отзывов и старое разрешение `reviews`.
Скрипт нельзя запускать, пока рабочий сайт ещё использует старый код.
Исторические миграции сохранены как история схемы, работающий код их не вызывает.

Проверки: `node tests/attendance-retirement.cjs`,
`node tests/employee-session.cjs`, `npm run build`.

Владелец разрешил публикацию кода в публичный репозиторий
`michel1378/warehouse-pick-counter`. Перед очисткой истории необходимо
подтвердить успешную публикацию версии без страниц и API отзывов.
