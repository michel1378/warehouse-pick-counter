# Подбор размеров по меркам и посадке

## Рабочий интерфейс

Администратор (`/admin/sizes`, `/admin/sizes-preview`) и сотрудники (`/sizes`)
используют один компонент и один расчёт. Вход и ограничения ролей сохранены.
Порядок полей: рост, вес, плечи и ширина груди вещи (для брюк — полупояс
без растяжения), затем «В облипку / В размер / Свободнее».
Длина, рукав и укороченность в рабочей форме не запрашиваются.

Один ввод возвращает все цвета. Для Чёрного Холода чёрный и серый имеют
одну сетку, поэтому название цвета не выводится. Альпака с пуговицами
рассчитывается отдельно для тёмно-серого, светло-серого и светло-бежевого.

Выводы не обозначаются как новые подтверждения или реальные примерки.

## Принцип расчёта

- Обычная посадка строится по примерам конкретной модели и цвета, с большим
  влиянием близких параметров. Ограничения по согласованным примерам и
  монотонная интерполяция по весу устраняют уменьшение размера при прибавке веса.
- Посадка корректирует эту основу. Отдельный единственный пример больше
  не создаёт постоянную модель для всех клиентов. Приоритет имеют реальные
  пары примеров посадок; неподтверждённое равенство с обычной посадкой из
  одного прогноза не превращается в исключение для всей модели.
- Результаты упорядочены: в облипку <= в размер <= свободнее. Для свободной
  посадки увеличение бирки проверяется по реальному объёму. Например,
  у Лучшей 2XL и 3XL почти совпадают по ширине; увеличение не гарантирует свободу.
- Плечи, грудь и полупояс сравниваются с сеткой с учётом выбранной посадки,
  растяжимости и застёгнутых пуговиц. Плечи сами по себе не доказывают,
  что заведомо меньший объём груди подойдёт. Согласованные исключения
  по меркам применимы и к близким профилям с теми же мерками.
- Явно несовместимые мерки получают «Нет размера» с конкретной причиной.
  Пример: у Фактурной рубашки грудь максимум 54 см, любимая вещь 60 см.
  Старое условное 3XL больше не изображается как подходящий размер.
- Отсутствующий размер не заменяется соседней биркой автоматически.
  Вне верхних границ имеющихся ориентиров нужны мерки подходящей вещи;
  это не выдаётся за проверенную посадку по одному росту и весу.

Сохранены исключения магазина: Мужик 183/78 свободнее — L; Альпака без
пуговиц 172/74 с плечами 50 и грудью 53 — L; Лучшая 175/80 — 2XL;

## Реальные ограничения

У Огромнейших и Альпаки с пуговицами нет полных сеток: они продолжают
подбираться по своим примерам. Введённый замер не объявляется использованным,
если связать его с биркой нечем. Для Огромнейших сохранён перемер конкретной
пары: у 2XL встречались полупояса 39 и 42–43 см.

У Цветов исходная грудь L=60, XL=56: сомнительный замер L не используется
для сравнения груди. Число не исправляется выдуманным значением.
У Самурайки рукава всего 58–60 см во всём ряду; известный случай 183/80
с коротким рукавом требует проверки длины и не лечится выдачей большей бирки.
Расчётные XL–5XL Чёрного Холода приняты владельцем без обязательного перемера.

## Сохранённые примеры из редактора

Все модели используют живые `size_products.examples`, а не только четыре
модели с `catalogAnchors`. Статический снимок старых примеров не подмешивается
повторно: удалённые в редакторе строки не возвращаются из сборки.
Проверенные поправки владельца сохраняют приоритет над противоречащими старыми
строками. Остальные старые примеры участвуют в расчёте соседних роста и веса;
их влияние ниже, чем у проверенных поправок. Примеры, противоречащие границам
согласованных размеров, не становятся ограничениями для соседних клиентов.

При сохранении сервер помечает `confirmedAt` только у добавленных или изменённых
примеров. Такая явная поправка из редактора обновляет старый ориентир, в том
числе скомпилированный. Сохранение фото, подписи или перестановка строк
не подтверждает устаревшие примеры заново. Повторное сохранение сохраняет
исходную отметку. Клиент не может прислать собственный `confirmedAt`.
Предпросмотр в редакторе применяет тот же механизм сравнения строк.

У альпак с пуговицами новые и изменённые рекомендации требуют `colorId`:
один цвет не перезаписывает другие. Старые записи без цвета сохраняются
как исторические ориентиры с учётом проверенных правил каждого цвета.
Редактор показывает выбор цвета только для модели, у которой проверенные
размеры цветов различаются. Реальные удачные примерки имеют приоритет
над предположительными рекомендациями; несовместимые мерки вещи блокируют
выдачу размера независимо от примера. При последующих поправках из переписки
нужно также проверить конфликтующие подтверждённые строки в живом каталоге.

тот же API и тот же подбор. Уже открытый каталог нужно обновить.
