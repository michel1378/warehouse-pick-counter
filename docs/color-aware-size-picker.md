# Подбор по цветам и меркам — проверка перед запуском

## Где включено

Новая форма открывается в административном каталоге `/admin/sizes`,
а также на `/admin/sizes-preview`. Поля мерок видны сразу, без раскрытия.
Обычный `/sizes`
продолжает использовать прежний подбор. Новая база, сервер или дополнительные
платные ресурсы не требуются.

Один ввод роста, веса и посадки возвращает ответы для всех проверенных цветов
модели. Для Альпаки с пуговицами это тёмно-серый, светло-серый и светло-бежевый.
Порядок формы: рост и вес, затем необязательные плечи и ширина груди
(для брюк и джинсов — полупояс без растяжения), затем посадка.
Это мерки вещи, а не обхваты тела. Длина и рукав в форме не запрашиваются.
Выбор укороченности убран; форма передаёт обычную длину.

## Источник и ограничения

В `src/lib/detailed-size-data.json` сохранён проверенный снимок согласований
владельца: версия 42, 11 моделей, 232 действующих правила. Полная переписка
в репозиторий не копируется. Подготовить следующий проверенный снимок:

```sh
python3 scripts/prepare-reviewed-sizes.py /absolute/path/michelle_sizes_draft.json
```

Программа учитывает исправленные рекомендации Самурайки и исключения по
Альпакам, Маржелам, Плотным, Огромнейшим и другим моделям. При наличии мерок
сравнивает их с сеткой; явные согласованные исключения сохраняются. Посадка
«свободнее» не означает автоматическое увеличение на один размер.

Расчётные замеры больших размеров Чёрного Холода помечены. Для Огромнейших
нужен замер конкретной пары; для спорной длины рукава Самурайки — проверка
экземпляра. Непроверенный новый цвет не получает рекомендацию соседнего цвета.
Отсутствующий в каталоге размер не заменяется соседним автоматически.

Согласованные примеры — регрессионные ориентиры, а не независимые примерки
и не доказанная точность для всех сочетаний роста и веса. Новые сочетания
дают предварительный ответ; несовместимые мерки требуют проверки.

## Проверка

```sh
node tests/detailed-sizes.cjs
node tests/size-preview-access.cjs
node tests/sizes.cjs
node tests/size-photos.cjs
npm run build
npm run typecheck
```

60 проверок новой логики охватывают согласованные примеры, все три цвета,
посадку, мерки, укороченность, ограничения сетки и отсутствие размера.
В браузере на синтетических данных проверены реальные компоненты формы:
три цвета Альпаки для 183/78, смена посадки, сброс клиента, изменение M на S
для Деревянных пуговиц при вводе мерок, поля брюк и исключение Плотных 183/88.
Это проверка интерфейса; полный сценарий на опубликованном сайте ещё не пройден.

Публикация кода в публичный `michel1378/warehouse-pick-counter` согласована
владельцем. После публикации сначала проверить новую
страницу с владельцем. Переключать рабочий подбор только после согласования.
